# Personal Portfolio

My personal portfolio website showcasing my work as a ServiceNow Platform Architect and Full Stack Engineer, with a focus on Bitcoin & Lightning Network development.

[Visit Portfolio](https://niteshbalusu.com)

## ⚡ Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS v4
- **Hosting:** AWS Amplify (build spec in `amplify.yml`)

## 🛠️ Setup & Development

### Prerequisites

- [Bun](https://bun.sh/)

### Installation

1. Clone the repository
```bash
git clone https://github.com/niteshbalusu11/nitesh-portfolio.git
cd nitesh-portfolio
```

2. Install dependencies
```bash
bun install
```

3. Start the development server
```bash
bun run dev
```

4. Build for production
```bash
bun run build
```
